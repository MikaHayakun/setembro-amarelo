# Fontes locais

- `bricolage-grotesque.woff2`: Bricolage Grotesque variável, dos autores do projeto Bricolage. Conversão e redução de caracteres para uso nesta interface.
- `cuidado-sans.woff2`: versão variável reduzida de Source Sans 3, da Adobe. O nome desta versão foi alterado para Cuidado Sans para respeitar o nome reservado na licença.

Originais: [Bricolage Grotesque](https://github.com/google/fonts/tree/main/ofl/bricolagegrotesque) e [Source Sans 3](https://github.com/google/fonts/tree/main/ofl/sourcesans3), obtidos do repositório oficial Google Fonts em 5 de outubro de 2026.

Os arquivos WOFF2 preservam caracteres latinos e acentos utilizados em português, pontuação e setas. As licenças SIL Open Font License 1.1 e os avisos de autoria estão nos arquivos `BricolageGrotesque-OFL.txt` e `SourceSans3-OFL.txt`. As fontes são carregadas pelo servidor local; não há requisições a provedores externos de fontes.
